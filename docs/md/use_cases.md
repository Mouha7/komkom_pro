# **Fonctionnalités par rôle**

### **Hardware Store Owner (Buyer)**

* Créer un compte / Signup
* Éditer le profil de l’entreprise
* Ajouter des employés
* Parcourir le catalogue produits (recherche, navigation par catégorie)
* Voir le prix des produits
* Ajouter des produits au panier
* Passer des commandes (checkout)
* Voir l’historique des commandes
* Suivre le statut d’une commande

### **Employee (sous le Store Owner)**

* Se connecter / Login
* Parcourir le catalogue produits
* Ajouter des produits au panier
* Passer des commandes
* Voir l’historique des commandes

### **Admin (KomKom Team)**

* Créer / éditer / supprimer catégories
* Créer / éditer / supprimer produits
* Définir les prix des produits
* Définir la disponibilité / statut de stock (Available / Not Available)
* Voir tous les magasins (stores)
* Voir toutes les commandes
* Changer le statut des commandes (Pending, Confirmed, Preparing, Out for Delivery, Delivered, Cancelled)
* Assigner la livraison
* Ajouter des frais de livraison
* Suspendre des comptes
* Exporter des données
